GRAMMAR – Comparative Adjectives

1. Tính từ ngắn

S + be + adjective-er + than + noun/pronoun
  • slow → slower
  • tall → taller
  • strong → stronger

2. Quy tắc thêm -er

  • Phụ âm + y: easy → easier; happy → happier
  • 1 âm tiết tận cùng y: shy → shyer
  • -er / -le / -ow: clever → cleverer; simple → simpler; narrow → narrower
  • Tận cùng e: large → larger
  • CVC: big → bigger; hot → hotter

3. Tính từ dài

S + be + more + adjective + than + noun/pronoun
  • beautiful → more beautiful
  • delicious → more delicious
  • difficult → more difficult

4. Dạng bất quy tắc

  • good → better
  • bad → worse
  • far → farther / further
  • little → less
  • many / much → more
